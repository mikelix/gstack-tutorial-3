# Market Benchmark — What Is This Deck Actually Worth?

**Why this file exists, and why it is separate from the tutorial itself.**
The tutorial's own `reviews/01-ceo-review.md` (Blocking issue B2) rejected an
earlier draft's ungrounded "85-95% production-ready" claim for exactly the
reason a bare dollar figure on the deck would be wrong here: an unverifiable
number stated as fact undermines everything around it. This file keeps the
valuation reasoning **out of** `TUTORIAL.md` and `dist/`, with its sourcing
visible, rather than asserting a number inside the teaching material.

---

## The market has (at least) two different products called "McKinsey-style"

Search conducted 2026-09-16. Full source list at bottom.

| Tier | Rate | What is actually bundled |
|---|---|---|
| Elite strategy consultant (McKinsey/BCG/Bain) | **$5,000+/slide minimum** | Derived from real published engagement contracts ($2.53M Dept. of Interior, $7.92M State of Michigan, $2.28M NJ BPU) over decks of ~100 slides. Bundles months of primary research, client interviews, market sizing, stakeholder workshops. GSA 2024 federal rate card: Senior Partner $1,193.57/hr, Engagement Manager $834.40/hr, Analyst/Associate $327-498/hr. |
| Big 4 (Deloitte/EY/KPMG/PwC) | **$3,000+/slide minimum** | Same shape, one tier down. Minimum project fees ~$300K. Partner ~$481/hr, consultant ~$263/hr. |
| Professional design agency, consulting-style | **$50-$300/slide**; full packages **$1,500-$10,000** | Applies consulting visual language (navy palette, data-ink tables, action titles) to content the client supplies. No primary research bundled. |
| Freelancer / AI-assisted | **$10-$160/slide** | Wide quality variance, no strategic content development. |

**The elite-consultant price is not a design price.** It is an analytical-
engagement price where a slide is the visible tip of months of research. The
design-agency tier is the actual comparable for "professionally styled deck,"
because that tier — like this project — starts from content someone else
(or, here, this session) already developed.

## Where gstack Tutorial #3's deck honestly sits

**Not elite-consultant tier.** No client, no paid primary research, no
stakeholder interviews, no market sizing. Claiming that tier's price would
repeat the exact B2 mistake — an unverifiable number borrowed from a context
that doesn't apply.

**Top of the design-agency tier, for a specific reason.** A $50/slide agency
service formats content handed to them. This deck's content was not handed
in — the governing finding (a free translator silently returning untranslated
English and exiting 0, defeating four of five verification gates) was
discovered, reproduced, and fixed *during* this project, with the deck built
from that real result rather than from filler case-study content. That
pushes it toward the top of the agency band, not into elite-consultant
territory, which requires sustained primary research this project never did.

## The number, with its derivation shown

```
31 slides x $300/slide (top of design-agency band)  = ~$9,300   (one edition)
Two language editions + two Word documents          = ~$15,000-$20,000 (full bundle)
```

This is a **market-comparable estimate using agency design rates**, not an
appraisal and not an elite-consultancy valuation. State it with that
qualifier attached, every time — the qualifier is not optional decoration,
it is the difference between this estimate and the B2 mistake.
